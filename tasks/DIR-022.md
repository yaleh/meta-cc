## Finding

`internal/analysis/service.go:389-394`: when `source_dir` is provided and `ScanSourceDir` fails, the error is discarded. Comment says "Degrade gracefully: log and return session-only result" but no log call exists. Users get session-only results with no indication the source scan was skipped.

## Proposal

Add `slog.Warn` call before the `return marshalResult(result)` fallback, logging the source_dir and error.

- [ ] ScanSourceDir failure is logged at WARN level
- [ ] Log message includes source_dir and error details
