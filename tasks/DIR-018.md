## Finding

In `internal/analysis/service.go:118-123`, `loadData` does `continue` when `ParseEntries()` fails — with no warning. If 80% of session files are corrupted, analysis returns results from 20% with zero evidence of data exclusion. Same anti-pattern across 4 locations; DIR-006/007 fixed 2.

## Proposal

Accumulate parse-failure warnings per file. Add `Warnings []string` to analysis result types. Log each skipped file at WARN level. Surface warnings in MCP tool responses.

## AC

- [ ] `loadData` accumulates parse-failure warnings per file
- [ ] Analysis result types include `Warnings` field
