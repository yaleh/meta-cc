## Finding

meta-cc has seven accepted ADRs (ADR-001 through ADR-007) in `docs/architecture/adr/`, but `quay adr list` returns zero results: the native provider's default ADR directory `./adr` is empty, and the existing ADR markdown files lack the YAML frontmatter the quay-native ADR store requires. Architectural decisions remain invisible to the quay task system.

## Proposal

Point the native provider at the real ADR directory and bring the files up to the store's format:

1. Set `QUAY_NATIVE_ADR_DIR: "./docs/architecture/adr"` in `.quay/config.yml` (providers.native.env).
2. Add the required YAML frontmatter (id, title, status, date) to each ADR-001..007 file, preserving the existing markdown body verbatim; status `accepted` for all seven.
3. Verify with `quay adr list` (MCP `adr_list`) that all seven appear, and spot-read one via `adr_get`.
4. Update `docs/architecture/adr/README.md` and CLAUDE.md to note architecture decisions use the ADR lifecycle (proposed → accepted → superseded/deprecated), not the directive lifecycle.

The exact frontmatter fields MUST be checked against quay-native's ADR parser before writing (`/home/yale/work/quay/packages/quay-native/src/`, adr read path) — do not guess the schema.
