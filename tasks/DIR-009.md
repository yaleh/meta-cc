## Finding

The project has 6 accepted ADRs in `docs/architecture/adr/` (ADR-001 through ADR-006)
that are invisible to the quay task system. `quay adr list` returns zero results.
Directive tasks (DIR-001, DIR-004) are being used to make architectural decisions
that should be ADRs (error classification taxonomy, pagination contract).

## Proposal

Register each existing ADR via `adr_write` with status `accepted`, preserving the
existing markdown body. Establish the convention: architectural decisions use the
ADR lifecycle (proposed -> accepted -> superseded/deprecated), not the directive
lifecycle (todo -> ready -> done).
