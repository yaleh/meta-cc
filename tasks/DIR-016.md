## Finding

`Skill({skill:"drain-directives"})` crashed with `undefined is not an object (evaluating 'args.workspaceRoot')` at workflow.js:6:52 (session `b2520f9f`). The same workflow succeeded 191s later when retried with explicit `args`. The Skill->Workflow bridge does not auto-inject common parameters like `workspaceRoot` and `provider`.

## Proposal

Add parameter validation boilerplate to workflow scripts: check `args?.workspaceRoot` before using, fail with a clear error. Consider auto-injecting `workspaceRoot` and `provider` in the Skill->Workflow bridge.
