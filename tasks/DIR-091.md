## Finding

Worktree subagents build in `/tmp/meta-cc-worktrees/<id>`. Full `make commit` runs ~62s each; 79 acceptance runs since 2026-07-28 cost ~82 min of wait, with retries (DIR-056 ×9, DIR-053 ×5, DIR-058 ×4). If each worktree builds with a cold Go cache, every first build/test pays full compilation cost on top of that. Whether GOCACHE/GOMODCACHE/GOPATH are shared across worktrees — so Go's content-addressed build and test caches stay warm — is unverified. DIR-008 proposed an environment-validation gate for worktree subagents but was closed-obsolete: its gate script was never checked into `scripts/` (invocation moved to the loop-driver deps-ready step, which lives in the quay skill repo). The repo-scoped artifact this task can own is the cache-sharing verification and documentation.

## Dependencies

None. Complements DIR-090 (scoped fail-fast checks reduce per-retry cost; warm caches reduce per-run cost).

## Scope

Audit and document the Go cache environment inherited by worktree subagents, add a repo-local check script that asserts caches are shared, and record expected env in `.quay` config comments/docs. Do not modify quay loop-driver skill code — it lives in a different repository (Quay Workspace Boundary).

owner_repo: meta-cc

## Plan

1. Audit what `GOCACHE`, `GOMODCACHE`, and `GOPATH` a worktree subagent at `/tmp/meta-cc-worktrees/<id>` actually inherits; record measured values with evidence.
2. Add `scripts/checks/check-worktree-cache-env.sh`: reports resolved GOCACHE/GOMODCACHE values, passes when they point at shared (non-worktree-local) locations, fails on per-worktree isolation (e.g. a cache path under the worktree or an empty HOME-derived default), and warns when a worktree would build with a cold cache.
3. Prove warmth: build one worktree, then build a second worktree for another task and attach evidence of cache hits (timing comparison or a `go build -x` trace showing cached artifacts).
4. Document expected env and the check in `docs/guides/plugin-development.md`.
5. Add comments in `.quay/config.yml` recording the expected shared-cache environment for dispatched worktree builds.
