## Finding

Subagents fail 5 Edit operations because the string-to-replace in the prompt does
not match the file on disk. Evidence:

- Session `2a38491e`, agent a60fc814e4c45f4af (DIR-004 build): 3 consecutive Edit failures
- Session `2a38491e`, agent accd3f1c38e10f5c0 (DIR-003 test fix): Edit failure + no-op edit
- Session `eb482896`, agent a3c8d9c3a74cd7d3f (DIR-005 build): Edit failure

Root cause: subagent dispatch prompts embed code snippets that the subagent
attempts to Edit without first Reading the actual file.

## Proposal

Add a "Read before Edit" instruction to the subagent dispatch prompt template.
Update the loop-driver skill to include: "ALWAYS Read a file before Editing it.
The code in this prompt may be stale."
