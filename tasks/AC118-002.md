## Finding

The errors package (internal/errors/errors.go) declares sentinel errors for
not-found, invalid-input, missing-parameter, unknown-tool, timeout, file-IO,
network, parse, and config conditions — but has no sentinel for a
duplicate-resource condition. Callers that must report "already exists" either
invent ad-hoc strings or reuse ErrInvalidInput, which conflates a duplicate
resource with a malformed input and breaks errors.Is() symmetry with the other
sentinels. A dedicated ErrDuplicate sentinel restores consistent error
checking.
