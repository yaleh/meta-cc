## Finding

`EnsureDir` in internal/ftsindex/location.go creates the FTS index directory
and writes a `.gitignore` inside it so the derived database is never committed.
The `.gitignore` write is done with `_ = os.WriteFile(...)`, silently discarding
the error even though the function already returns an error and callers expect
I/O failures to propagate. If the write fails the caller sees a nil error and
the derived database is left un-guarded against accidental commits. The error
should be returned.

## AC

- [ ] EnsureDir propagates the .gitignore write error instead of ignoring it
- [ ] Directory-creation behavior is unchanged (nil error when all writes succeed)
- [ ] `go build ./...` passes

## DoD

- [ ] internal/ftsindex/location.go returns the .gitignore write error
- [ ] `go build ./...` exits 0
