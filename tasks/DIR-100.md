## Finding

`scripts/release/release.sh` Step 1 pre-release validation is dead code in the current tree, and the release path's test phase is unbounded. Together this produced a recurring release-failure/timeout chain in the loop driver.

Structural defects:

1. **Path mismatch → validation permanently skipped (fail-open).** `release.sh` guards with `[ -f "scripts/pre-release-check.sh" ]`, but the script actually lives at `scripts/release/pre-release-check.sh`; `scripts/pre-release-check.sh` does not exist (verified on current tree: `ls: cannot access 'scripts/pre-release-check.sh': No such file or directory`). Every release run therefore takes the fallback branch and prints `⚠️  Warning: pre-release-check.sh not found (skipping validation)` — real pre-release validation never runs.
2. **Warn-and-continue masks the breakage** — the fallback degrades to minimal "Basic checks" and proceeds silently instead of failing closed.
3. **Unbounded test phase** — the fallback's `Run tests...` phase runs the full verbose suite with no timeout, so the loop driver's Bash watchdog kills a half-finished release at 10 minutes.

Evidence — session `2895bdb9-1e32-4af8-9906-73db13b7a584` (2026-07-30), three chained events:

- `06:26:59Z`: `Exit code 2 / Creating release v3.7.0... / Step 1: Running pre-release validation... / ⚠️  Warning: pre-release-check.sh not found (skipping validation) / Basic checks: / Error: Working directory not clean. Commit or stash changes. / make: *** [Makefile:214: release] Error 1`
- `06:27:16Z`: same `pre-release-check.sh not found (skipping validation)` warning, retry proceeds into `Basic checks: Running tests...`
- `06:37:26Z`: `Exit code 143 / Command timed out after 10m 0s / [main d4cd60f] chore: fix formatting in consistency test ... Creating release v3.7.0... / Step 1: Runni...` — release killed mid-run, left half-finished.

The analyze_bugs fix-pair analyzer independently flags this shape as recurring (error signature `77af6e2589fbfb5d`: fix_count=2, recurrences=2), with examples quoting both the `pre-release-check.sh not found (skipping validation)` + `Working directory not clean` failure and the skip-then-tests path.

This contradicts the documented contract that repo validation targets complete within bounded time (CLAUDE.md: `make push` full check "<120s"); a release should not consume a 10-minute watchdog budget.
