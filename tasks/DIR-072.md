## Finding

DIR-032 added completeness, compaction, lifecycle, archive, pagination, and lineage semantics, but current 0.145-shaped fixtures still leave `world_state`, `tool_search_call`, `tool_search_output`, and `thread_settings_applied` as opaque raw items. This preserves bytes but prevents callers from filtering, correlating, summarizing, or safely excluding these events by stable semantic fields. Documentation explicitly records this passthrough limitation, so the prior task can remain complete while this follow-up closes the remaining queryability gap.

## Contract

- Each supported event family maps to a typed canonical item with stable kind, timestamp, turn/session identity, source, and structured fields.
- Tool search calls and outputs correlate by call identity and retain status/error information without being confused with shell/function tools.
- World-state and thread-setting records expose bounded metadata while large or sensitive payloads remain redacted, capped, or available only through explicit raw access.
- Unknown future events continue to survive as raw passthrough with provenance and warnings where appropriate.
- Legacy and app-server projections do not duplicate equivalent typed events.

## Plan

1. Define canonical item kinds and minimal structured payloads for the four event families.
2. Extend rollout parsing and provider normalization while preserving stream order.
3. Add query/filter and tool-stat behavior where the event semantics warrant it.
4. Establish size/privacy limits for world-state and settings payloads.
5. Add paired legacy/current fixtures plus unknown-event forward-compatibility tests.

## Acceptance Criteria

- [ ] All four known event families produce typed canonical items rather than generic unknown items.
- [ ] `tool_search_call` and `tool_search_output` correlate correctly and surface failures.
- [ ] World-state/settings payload handling is documented, bounded, and tested for sensitive or oversized data.
- [ ] Equivalent dual-source events are not duplicated.
- [ ] Unknown future events still round-trip as raw items.
- [ ] `make commit` passes.
