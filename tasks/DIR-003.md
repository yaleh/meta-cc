## Finding

`get_tech_debt` currently scans only Claude Code session transcripts for TODO/FIXME/HACK
markers. This means it finds markers mentioned in conversation but misses all markers in
actual source code. For quay, which has extensive TODO/FIXME markers in `tasks/`,
`milestones/`, and source files, the result (9 TODOs) is misleadingly clean.

Root cause: `GetTechDebt()` in `internal/analyzer/tech_debt.go:47-66` iterates only over
`[]types.ToolCall` from session JSONL files. The `markerPattern` regex (line 10) matches
`\b(TODO|FIXME|HACK|XXX)\b` but only within `Read`/`Edit`/`Write`/`Bash` tool-call output
text captured in transcripts — never on source files on disk.

## Proposal

Add an optional `source_dir` parameter to `get_tech_debt`. When provided, the tool
additionally walks the directory tree scanning source files for the same marker pattern.
Results from source-code scanning are merged with session-transcript results, with each
marker attributed to its source (file path vs session).

The implementation follows the established codebase patterns:
- `source_dir` parameter added via `BuildTool` in `tools.go` (same pattern as `get_timeline`'s `working_dir`)
- New `ScanSourceDir(sourceDir string) (*TechDebtResult, error)` function in `tech_debt.go`
- Merge performed in `Service.GetTechDebt()` in `service.go` (same layer that calls `loadData`)

## Plan

### Phase 1: Add source_dir parameter to tool schema
- **File:** `internal/mcp/tools/tools.go` (line 244, `get_tech_debt` definition)
- Add `source_dir` property: `{Type: "string", Description: "Optional path to source code directory to scan for TODO/FIXME/HACK/XXX markers on disk. Results merged with session-transcript markers."}`

### Phase 2: Add source-code scanning function
- **File:** `internal/analyzer/tech_debt.go`
- Add `ScanSourceDir(sourceDir string) (*TechDebtResult, error)`:
  - `filepath.Walk` the directory tree
  - Filter by known code extensions: `.go`, `.py`, `.ts`, `.js`, `.tsx`, `.jsx`, `.java`, `.rs`, `.c`, `.h`, `.cpp`, `.hpp`, `.sh`, `.yaml`, `.yml`, `.md`, `.json`, `.toml`
  - Skip hidden directories (`.git`, `node_modules`, `vendor`, `.venv`, `__pycache__`)
  - For each file, scan line-by-line with the same `markerPattern` regex
  - Build `[]MarkerCount` and `[]FileDebt` with `DataSource: DataSourceMeasured`
  - Cap at 10,000 files scanned (safety limit)

### Phase 3: Merge results in service layer
- **File:** `internal/analysis/service.go` (line 377, `GetTechDebt` method)
- Extract `sourceDir := stringArg(args, "source_dir")`
- If `sourceDir != ""`:
  - Call `ScanSourceDir(sourceDir)`
  - Merge markers: add counts from both sources, deduplicate hotspot files by path
  - Merge open issues (source scan has none; session scan contributes its estimate)
  - Set combined `DataSource` to `DataSourceMeasured`

### Phase 4: Update tests
- **File:** `internal/analyzer/tech_debt_test.go` — add `TestScanSourceDir` with temp directories containing known markers
- **File:** `cmd/mcp-server/analysis_techdebt_test.go` — add integration test with `source_dir` parameter
- Run `make commit` to validate
