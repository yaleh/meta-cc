## Finding

`get_tech_debt` currently scans only Claude Code session transcripts for TODO/FIXME/HACK
markers. This means it finds markers mentioned in conversation but misses all markers in
actual source code. For quay, which has extensive TODO/FIXME markers in `tasks/`,
`milestones/`, and source files, the result (9 TODOs) is misleadingly clean.

## Proposal

Add optional source-code scanning: when a workspace path is provided, scan source files
for TODO/FIXME/HACK markers in addition to session transcripts. Combine results with
source attribution (file vs session).

## Acceptance Criteria

- [ ] `get_tech_debt` accepts optional `workspace` or `scan_source` parameter
- [ ] Source-code TODO/FIXME/HACK markers included in results
- [ ] Results distinguish source-file markers from session-transcript markers
- [ ] Quay project scan returns >>9 results (current baseline)
