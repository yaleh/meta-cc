## Finding

The repository already derives the live MCP tool count in `internal/release/consistency_test.go`, but validates only a curated list of prose patterns. This allowed README to advertise a stale 15-tool breakdown while tests passed. Markdown lint is informational, and there is no current-doc gate for removed tool names, broken navigation links, or a Go prerequisite that disagrees with `go.mod`.

## Dependencies

DIR-074, DIR-075, and DIR-077 establish the corrected baseline and the explicit boundary between current, migration, and historical documentation. This task should encode that boundary after the content is clean.

## Scope

Add a deterministic offline documentation contract check. Prefer structured allowlists for intentional legacy mentions and excluded historical directories over broad regex rewriting. Diagnostics must identify the file, line, stale claim, and accepted replacement. Keep the gate fast enough for `make commit` and normal CI.

## Touches

- `internal/release/` or a focused documentation-check package
- `scripts/` only if a small checker is clearer than Go tests
- `Makefile` and CI wiring
- a checked-in allowlist or status manifest for intentional historical and migration references

## Plan

1. Define current, migration, generated, fixture, and historical documentation scopes.
2. Validate tool-count claims against `tools.GetToolDefinitions()` and ensure documented current tool names exist in the registry.
3. Reject removed tool invocations in current executable examples while allowing labeled migration mappings.
4. Validate internal documentation links and the documented Go version against `go.mod`.
5. Wire the check into `make commit` and CI with actionable failures and focused tests for false positives.

## Acceptance Criteria

- [ ] Changing a current tool count or category summary to a stale value fails offline with the file and mismatch.
- [ ] Adding a removed tool invocation to a current guide or example fails, while an explicitly allowed migration table passes.
- [ ] A broken relative link in a current index or guide is detected.
- [ ] A documented Go prerequisite below the repository baseline is detected.
- [ ] Historical proposals, plans, archives, task records, and captured fixture output do not produce false positives.
- [ ] The new check runs through `make commit` and CI.
- [ ] `make commit` passes.
