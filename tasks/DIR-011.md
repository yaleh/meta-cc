## Finding

`output_format` parameter is documented in `tools.go:45` as "Output format: jsonl or tsv" and stored in `PipelineConfig.OutputFormat` (`executor.go:39`, `pipeline.go:28`), but none of the four response builder functions (`BuildResponse`, `BuildStandardResponse`, `BuildStatsOnlyResponse`, `BuildStatsFirstResponse`) ever read `pc.OutputFormat`. A user passing `output_format: "tsv"` silently receives JSONL. Full TSV support exists in `internal/output/tsv.go` and `internal/output/tsv_test.go` but is never wired in.

## Proposal

Wire `OutputFormat` into `BuildStandardResponse` (the main user-facing response path) to dispatch between JSONL and TSV formatting using the existing `internal/output/tsv.go` code.

## AC

- [ ] `output_format: "tsv"` returns tab-separated data
- [ ] `output_format: "jsonl"` (or unset) returns JSONL
- [ ] Invalid values are rejected with a clear error
