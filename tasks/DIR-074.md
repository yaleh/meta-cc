## Finding

Current user-facing overview documentation has drifted from the shipped v3.6 implementation. `README.md` advertises both 16 MCP tools and a stale 15-tool taxonomy, omits `query_sessions` from the quick-start story, claims `since` and `until` apply to all query tools, and still lists Go 1.21 despite the repository targeting Go 1.24. `docs/reference/features.md` says 16 tools but its category list accounts for only 15 because `query_sessions` is missing. The existing release consistency test does not catch the README wording.

## Scope

Update the concise product overview without duplicating the full MCP reference. Derive the taxonomy from the live registry, describe `query_sessions` as metadata-first discovery, qualify which tools accept shared time filters and response controls, state the supported Go toolchain consistently with `go.mod`, and link to the authoritative query and Codex reference pages. Use wording such as no external runtime dependencies instead of an ambiguous zero dependencies claim.

## Touches

- `README.md`
- `docs/reference/features.md`
- `docs/guides/mcp.md` only where its overview contradicts the live schema
- `internal/release/consistency_test.go` only for focused coverage of claims changed by this task

## Plan

1. Compare overview claims with `tools.GetToolDefinitions()` and the parameter schemas.
2. Correct the tool count, category arithmetic, prerequisites, filter scope, and quick-start examples.
3. Add a short `query_sessions` discovery-to-content example and links to detailed references.
4. Add focused regression coverage so both the total and the category summary cannot silently drift again.

## Acceptance Criteria

- [ ] Every current overview reports the live MCP tool count and a category breakdown that sums to it.
- [ ] `query_sessions` is visible in the README and feature catalog as the session discovery entry point.
- [ ] Time-filter and output-control claims name the tools that actually support them rather than saying all tools.
- [ ] The documented Go requirement matches `go.mod` and repository policy.
- [ ] Historical documents are not rewritten merely to update old counts.
- [ ] `make commit` passes.
