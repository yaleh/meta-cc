## Finding

`query_session_content` and `query_session_signals` declare `since`/`until` as global parameters but only apply them for `role=user`, `role=all`, and `type=timestamps`. All other paths silently ignore: role=assistant (`consolidated_handlers.go:50-66`), role=tool (`consolidated_handlers.go:67-69`), type=errors/tokens/system_errors/tool_stats. Users pass `since`/`until` and get unfiltered results with no warning.

## Proposal

Pass `since`/`until` through to `ExecuteQueryForProvider` in all handler paths, or return a clear error when they're used with unsupported role/type combinations.

## AC

- [ ] `query_session_content(role=assistant, since=...)` applies time filter
- [ ] `query_session_signals(type=errors, since=...)` applies time filter
- [ ] Or: clear error when since/until used with unsupported paths
