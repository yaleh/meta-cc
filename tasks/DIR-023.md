## Finding

`internal/mcp/response/adapter.go:17` reads `output_mode` from params to control inline vs file_ref mode, but `output_mode` is NOT declared in any tool schema. All tool calls go through `ValidateToolArgs` which rejects undeclared parameters. Passing `output_mode` ALWAYS causes a hard error. Tests bypass the validation path, so they pass.

## Proposal

Either register `output_mode` in the standard tool parameters schema, or remove the dead code from `adapter.go` and update tests.
