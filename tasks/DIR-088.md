## Finding

Measured 2026-07-30: `make check-essential` = 15.6s and includes `check-path-independence`, which spawns a nested `env -i PATH=/usr/bin:/bin make _path-independence-probe` (~5–8s of the 15.6s). `make commit` = check-essential + check-no-scanner + test ≈ 62s measured (budget says <60s). check-path-independence guards against regression of the Makefile's own PATH-hardening line (DIR-035) — the Makefile changes rarely, yet every `make commit` pays the nested-probe cost.

## Dependencies

None. Preserves the DIR-035 regression check; only its tier changes.

## Scope

Move `check-path-independence` out of `check-essential` into the push tier (or cache its result keyed on Makefile content hash). The regression check itself stays intact and must still fail if the `export PATH :=` hardening line is removed. Commit-tier gates otherwise unchanged.

owner_repo: meta-cc

## Touches

- Makefile

## Plan

1. Trace `make commit` to confirm the nested `env -i make` probe runs on every commit; record its timing.
2. Remove `check-path-independence` from the `check-essential` dependency list.
3. Add it to the push-tier target chain (or implement the Makefile content-hash cache with invalidation on Makefile edits).
4. Negative test: temporarily remove the PATH-hardening line and confirm `make push` fails at the probe; restore.
5. Re-measure `make check-essential` and `make commit`; attach timings to the task.

## Acceptance Criteria

- [ ] `make commit` no longer spawns the nested `env -i` probe (verifiable in command trace).
- [ ] `make push` still runs check-path-independence.
- [ ] Removing the `export PATH :=` hardening line still fails the check (negative-test evidence attached).
- [ ] `make check-essential` wall time drops by ≥5s measured.
