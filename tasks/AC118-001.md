## Finding

`EstimateToolCallsSize` (internal/output/estimator.go) handles the empty-input
case correctly only for the `json` format, where `len(tools)==0` returns the
2-byte `[]` estimate. For `md`/`markdown`, `csv`, and the `default` branch the
function returns a fixed non-zero size (500 / 100 / 0 bytes respectively) even
when there are zero records, so an empty result is reported as ~500 bytes of
output. Empty output should estimate 0 bytes regardless of format, consistent
with the json branch.

## AC

- [ ] Empty input (`len(tools)==0`) returns 0-byte estimate for md/csv/default formats
- [ ] json format empty input stays 2 bytes (unchanged)
- [ ] Non-empty input estimates are unchanged
