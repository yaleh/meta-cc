## Finding

Several documents presented as current instructions still contain executable examples for tools removed by the consolidated query API, including `query_tools`, `query_user_messages`, `query_tool_errors`, and `query_token_usage`. Affected surfaces include the main MCP guide, integration and capabilities guides, test quickstarts, tutorials, cookbook examples, and the JSONL schema reference. Users following these examples receive tool-not-found errors even though `docs/guides/mcp-query-tools.md` already provides the correct legacy-to-current mapping.

## Scope

Audit normative guides, tutorials, testing instructions, examples, and reference pages. Rewrite executable examples to `query_session_content`, `query_session_signals`, `query_file_activity`, or `query_sessions` with equivalent filters. Preserve old names only in explicitly labeled migration tables and historical material under proposals, plans, phases, archives, and tasks. Mark superseded migration guides clearly if they describe an intermediate API that is no longer current.

## Touches

- `docs/guides/`
- `docs/tutorials/`
- `docs/examples/`
- `docs/reference/jsonl-schema.md`
- documentation tests or scripts added to verify examples

## Plan

1. Classify each old-tool occurrence as current executable guidance, migration mapping, historical record, or fixture output.
2. Convert current examples and surrounding prose to the consolidated API while preserving the intended result.
3. Add status banners or archive links to superseded migration documents that would otherwise mislead readers.
4. Validate representative JSON-RPC examples against the live tool schemas.

## Acceptance Criteria

- [ ] Current executable examples do not call removed MCP tools.
- [ ] Each converted example preserves its original intent and uses parameters accepted by the live schema.
- [ ] Intentional legacy names appear only in clearly labeled migration or historical contexts.
- [ ] MCP testing guides exercise currently registered tools.
- [ ] The JSONL schema reference points token, error, message, and tool-call concepts to current query tools.
- [ ] `make commit` passes.
