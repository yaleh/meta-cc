## Finding

Measured 2026-07-30: the Makefile `test` target uses `-v`, producing very large logs. Session transcripts show agents universally pipe through `tail -40` / `grep "^--- FAIL"` to cope — pure token and I/O waste. `go test` without `-v` already prints failing tests and their output verbosely enough on red runs; green runs do not need the per-test stream. Context: 79 acceptance gate runs in 2 days (≈82 min total) make this overhead recurring.

## Dependencies

None

## Scope

Change `test:` to `$(GOTEST) -short ./...` and add an opt-in `test-verbose` target that retains `-v` for debugging. Update `make help` accordingly. CLAUDE.md build/test quick-links are in scope only if they describe the current `-v` behavior. Do not change package selection or other flags — output verbosity only.

owner_repo: meta-cc

## Plan

1. Change the `test` target to `$(GOTEST) -short ./...` (no `-v`).

4. Grep CLAUDE.md for mentions of test output behavior and update if present.
5. Verify: a green run produces compact output and a deliberately red run still names the failing package and test.
