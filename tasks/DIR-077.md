## Finding

`docs/DOCUMENTATION_MAP.md` predates several active references and no longer represents the current information architecture. It omits the consolidated MCP query guide and the Codex app-server, history-model, and FTS-index references, leaving the main navigation Claude-centric. Some reference pages describe internal capabilities without making their public reachability obvious; for example, the FTS package exists but is not yet wired into an MCP tool.

## Scope

Refresh navigation and status metadata, not the underlying feature implementations. Give readers a short path for using meta-cc from Claude Code, a parallel path for Codex, and a contributor path for architecture and provider internals. Clearly label implemented public behavior, internal foundations, known limitations, and historical design records. Keep DIR-031 and other unfinished work described as pending rather than delivered.

## Touches

- `docs/DOCUMENTATION_MAP.md`
