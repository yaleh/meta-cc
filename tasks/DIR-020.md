## Finding

`isAllNullOrEmpty` is defined twice: `internal/query/engine/stage2.go:79` and `internal/mcp/query/query.go:391`. The two implementations are currently identical (the earlier divergence — stage2 returning jq errors properly while query.go silently discarded them — has been fixed), but the duplication itself remains: any future fix must be applied twice, and the functions already diverged once in practice.

## Proposal

Extract `isAllNullOrEmpty` (and its warning helper if shared) into a single shared location — e.g. `internal/query/common/` — and make both callers import it. Remove both duplicated definitions. Behavior must remain byte-identical for all edge cases (empty slice → false, non-map scalars → false, jq error propagation).

## Plan

1. Create the shared package/function with the current identical semantics.
2. Switch `stage2.go` and `query.go` to the shared import; delete local copies.
3. Run existing tests; add a small table-driven test in the shared package covering the edge cases above.
