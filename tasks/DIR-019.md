## Finding

`internal/analyzer/bugs_analysis.go` only counts errors that have a matching fix within a 3-position lookahead; errors without fixes are invisible. `BugAnalysisResult`/`BugAnalysisStats` have no total-error or unfixed-error count.

## Resolution (landed c94d7a1, 2026-07-30)

Every error occurrence is now counted independently of inferred fixes. Added `TotalErrors` and `UnfixedErrors` to all result types (full + stats). FIX: one-to-one fix matching via `consumed` map — each success is claimed at most once by the nearest preceding error in the 3-position lookahead. Recurrences documented as total error occurrences; FixCount counts only inferred fixes. Regression test: 2 errors + 1 success → FixCount=1, UnfixedErrors=1. Diff: 152 insertions, 30 deletions = 182 lines.

First attempt (dbad093, 207 lines) refuted: one success counted as fix for multiple errors. Replaced by this one-to-one implementation rebased onto main.
