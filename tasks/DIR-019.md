## Finding

`internal/analyzer/bugs_analysis.go:40-70`: bug pattern analysis only counts errors with matching fixes within 3-position lookahead. Errors without fixes ignored (`_ = found`). `fixCount` and `recurrences` always incremented together — semantically identical. Error occurring 100 times with zero fixes = zero recurrences.

## Proposal

Track `totalErrorCount` separately from `fixCount`. Add `UnfixedErrors` field to BugPattern. Rename `Recurrences` if always equal to `FixCount`.
