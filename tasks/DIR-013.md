## Finding

`status` parameter is documented at `tools.go:360-363` as "When type=tool_stats: filter by status (error/success)" but `handleQueryTools` (`handlers.go:73-88`) never reads it. The parameter passes schema validation but is silently ignored — filtering has no effect.

## Proposal

Add `status := GetStringParam(args, "status", "")` to `handleQueryTools` and, when non-empty, append a jq filter `select(.status == "status")` to the filter chain.

## AC

- [ ] `query_session_signals(type=tool_stats, status="error")` returns only error tool calls
- [ ] `status="success"` returns only successful calls
- [ ] Omitting `status` returns all calls (backward compatible)
